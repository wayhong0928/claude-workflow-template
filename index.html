Claude Code 工作流 template

給研究生用的 Claude Code 工作流程設定，裝進你自己的論文或筆記資料夾就能用。開場自動接上次進度，派 subagent 前先套派工模板，產出交給另一個 agent 驗收，另有幾支 hook 擋常見的錯。需要 Python 3，不需要會 Git。

到 GitHub 下載 安裝步驟 跟 Superpowers 比較

它解決什麼問題

一篇論文要寫好幾個月，會跨很多個 session。Claude Code 的 auto memory 由 Claude 自己決定要記什麼，不保證記下上次做到哪；--continue 只能接回上一段對話。派 subagent 做事時，常常沒交代清楚要什麼、做完怎麼算完成；做完了，也沒有人回頭核對。這個 template 把這幾件事分成兩類：

忘了也要發生的事交給 hook；需要判斷的事寫成規則，讓 Claude 照做。

hook 是 Claude Code 在特定時間點自動執行的腳本，可以注入內容，也可以擋下動作。規則寫在 .claude/rules/ 和 skill 裡，靠 Claude 自律，不一定每次都照做。

四個組成

接力

.claude/session-log-kit/

選裝。session_log 記做了什麼，TODO 記還沒做什麼。開場由 hook 注入最新一筆全文和前兩筆的下一步。專案不在 git repo 裡時，安裝程式預設會裝。

派工

.claude/skills/dispatch-template/

先問值不值得派，派就用模板寫清楚目標、驗收條件和回報格式，並指定模型。沒載入模板就派工，hook 會擋下。

驗收

.claude/agents/verifier.md

做的人不驗自己的活。依產出風險分三級，最高一級交給只拿到驗收條件、沒看過推理過程的 verifier。

護欄 hook

.claude/hooks/

一再犯的錯改成機制：寫出控制字元會被擋，context 過長會被提醒。hook 自己出錯時一律放行，不會卡住工作。安裝時用 --protect 指定的原始資料，由 Claude Code 的權限規則擋下修改。

一個 session 從開場到收尾

  1. 開場機制有裝 session_log 的話，SessionStart hook 注入 session_log 最新一筆全文，加前兩筆的標題與下一步。Claude 先用一兩句話報告上次進度。
  2. 決定要不要派 subagent自律主對話預設自己做。只有要隔離大量內容、有可獨立完成的工作包、或需要獨立驗收時才派。
  3. 派工前載模板機制這個 session 還沒載入 dispatch-template 就派工，dispatch_gate.py 會擋下並說明原因。
  4. 不過就續問或升級自律第一次不過先續問原 agent；再不過才換更強的模型，並附上兩次的失敗紀錄。
  5. 宣告完成前驗收自律依下面的三級表決定怎麼驗。
  6. context 過長時提醒機制主對話超過 15 萬 token，context_guard.py 提醒你在段落點補 log，再下 /clear。
  7. 回合結束掃控制字元機制本回合寫過的 .md、.json、.py 混進控制字元，ctrl_char_stop.py 會擋下。
  8. 收尾自律有裝 session_log 的話，用 add_session_log.py 在頂部補一筆（腳本檢查格式），刪掉做完的 TODO。

驗收分三級

級產出怎麼驗
0照抄使用者提供的內容、session_log、TODO、搬檔、單行修改不派 verifier，回報寫明理由
1批次修改、數字加總、程式、腳本、hook跑腳本或測試，把輸出貼出來當證據
2論文正文與文獻筆記、公開網站內容、規則檔、報告的結論與出處派 fresh-context 的 verifier，只給驗收條件與檔案；高風險判斷再加一路 opus 第二意見

完整規則在 .claude/rules/dispatch-and-verify.md。

開始使用

  1. 確認環境：Claude Code 2.1.292 以上、Python 3.8 以上。裝 session_log 還要 PowerShell（Windows 內建；macOS、Linux、WSL 要另外裝 PowerShell 7）。Git 不是必要的。檢查方法見 README 的環境表。
  2. 讓 AI 幫你裝：在你的專案資料夾開 Claude Code 或 Codex，貼上 README 裡的安裝 prompt。它會先檢查環境，缺什麼先問你，每一步等你同意才做。用 Codex 裝也可以，但裝好的東西只在 Claude Code 裡有作用。
  3. 或自己裝：下載 ZIP 解壓縮，執行 python install.py 你的專案資料夾 --dry-run（macOS、Linux、WSL 用 python3）看它要做什麼，沒問題再拿掉 --dry-run。原本的設定會保留，改動前先備份；不要了可以用 --uninstall 移除。

適合以寫作、研究為主、一個專案會跨很多 session 的人。Windows 原生在實機上跑過；WSL2（Ubuntu）跑過 hook 與安裝程式的測試；macOS 還沒測。用 WSL 的話，Claude Code 和安裝程式都在 WSL 裡跑。
